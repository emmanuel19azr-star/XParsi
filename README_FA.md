# XParsi — نسخه اولیه

این پروژه یک نمونه اولیه Expo / React Native برای اندروید است.

## امکانات فعلی
- رابط کاربری فارسی با تم تیره
- انتشار پست در فید محلی
- لایک و برداشتن لایک
- نوار پایین با بخش‌های نمایشی

## محدودیت‌ها
- حساب کاربری، دیتابیس، دنبال‌کردن، پیام‌رسانی و اعلان واقعی هنوز وصل نیستند.
- پست‌ها فقط در حافظه اجرای برنامه‌اند و با بستن/بارگذاری مجدد ممکن است پاک شوند.
- برای انتشار عمومی باید احراز هویت، ذخیره‌سازی سروری، قوانین امنیتی و تست اضافه شود.

## ساخت APK
نیازمند Node.js و حساب Expo/EAS است. پس از نصب وابستگی‌ها:
1. `npm install`
2. `npx eas-cli login`
3. `npx eas-cli build --platform android --profile preview`

این فرایند در زیرساخت Expo اجرا می‌شود و APK را پس از پایان build ارائه می‌کند.
